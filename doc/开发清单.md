## 结构与注释规范

- `op_host/`：host 调度模型与后续 CANN 注册/tiling。
- `op_kernel/`：真实 Ascend C device 代码；不放 CPU 原型冒充 kernel。
- `reference/cpp/`：可移植 CPU FP32 算法原型，不等同于 PyTorch/CANN 数学库。
- `src/cann_competition/`：Python oracle、候选及本地工具。
- `tests/cpp/`：C++ 算法及调度验证；`tests/`：Python 验证。
- C++ 使用 C++17、头文件 include guard、项目命名空间、4 空格缩进。
- C++ 接口注释使用 `@brief`、`@param`、`@return`、`@throws`、`@note`；按实际接口选择字段。
- Python 公共函数注明参数、返回和异常；私有辅助函数说明前提条件。
- 注释解释算法、边界和限制，不逐行重复代码；变更时同步维护注释。

## 本地验证命令

在项目根目录执行（当前 Windows 环境有 g++）：

```powershell
New-Item -ItemType Directory -Force build | Out-Null
g++ -std=c++17 -O2 -Wall -Wextra -Werror -pedantic -I . tests/cpp/test_prototype.cpp -o build/test_prototype.exe
./build/test_prototype.exe
$env:PYTHONPATH = Join-Path (Get-Location) 'src'
python -m unittest discover -s tests -v
python -m compileall -q src tests
```

C++ 对照验证的是同一 CPU 数学库下的选择等价性，并有零值和大正数评分检查；不能据此认定设备精度通过。Python FP32/FP16 数值验证需要 torch，缺少依赖时明确 skip。
