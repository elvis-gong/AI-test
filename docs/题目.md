# SqrtSoftplusTopK算子

## 一、赛题背景

Mixture-of-Experts（MoE）是当前大语言模型的主流扩展架构，模型由大量专家子网络构成，每个 token 在推理时只激活其中少量专家，从而在保持大参数量容量的同时控制推理成本。MoE 路由（gating）是决定每个 token 激活哪些专家的关键算子。

DeepSeek V4 采用 `sqrt(softplus(logits))` 作为专家评分函数，从众多路由专家中为每个 token 选出 top-k 个专家。该评分函数相比传统的 softmax 或 sigmoid 更平滑。

本题要求基于 PyTorch 中 DeepSeek V4 路由评分的核心业务逻辑，采用 Ascend C 编程语言进行算子原生开发，在昇腾 NPU 硬件上实现一款高性能的 SqrtSoftplusTopK 算子。

## 二、算子功能描述

实现的 SqrtSoftplusTopK 算子需完成以下核心计算：

1. 对 router\_logits 逐元素计算 softplus 评分，再开平方得到 `sqrt(softplus(x))` 评分
2. 依据评分为每个 token 选出 top-k 个专家，输出选中专家的评分（本赛题不输出top-k专家Id）

## 三、核心定义与约束

### 3.1 参考算子

PyTorch 中 DeepSeek V4 sqrtsoftplus 路由评分的等价实现：

```
import torch

def softplus(x):
    # softplus(x) = ln(1 + e^x)，数值稳定实现
    return torch.where(x > 20.0, x, torch.log1p(torch.exp(x)))

def apply_sqrt_softplus_topk(router_logits, k):
    # 1. 评分: sqrt(softplus(logits))
    scores = torch.sqrt(softplus(router_logits.float()))          # [T, E]

    # 2. 直接对 scores 降序排序，取 top-k 个值
    topk_scores = torch.sort(scores, dim=-1, descending=True).values[:, :k]  # [T, k]

    return topk_scores
```

### 3.2 数学公式

设输入 router\_logits 为 `x`，形状 `(T, E)`（T 为 token 数，E 为专家数），softplus 函数定义为：

$$
\text{softplus}(x) = \ln(1 + e^x)
$$

逐元素评分：

$$
\text{score}[t, e] = \sqrt{\text{softplus}(x[t, e])} = \sqrt{\ln(1 + e^{x[t, e]})}
$$

专家选择：基于 score 做 top-k 选择（降序，并列值按专家索引升序），得到每个 token 选中的 k 个专家索引：

$$
\text{ids}[t, :] = \text{topk}_e\left(\text{score}[t, e]\right)
$$

输出评分：用选中的索引取出对应的评分：

$$
\text{scores\_out}[t, j] = \text{score}[t, \text{ids}[t, j]]
$$

### 3.3 输入输出与属性总览

| 类型         | 参数名         | 类型   | 维度形状 | 支持数据类型     | 数据格式 | 备注                       |
| ------------ | -------------- | ------ | -------- | ---------------- | -------- | -------------------------- |
| INPUT(必选)  | router\_logits | tensor | (T, E)   | float16, float32 | ND       | 路由 logits                |
| ATTR(属性)   | k              | int    | \-       | \-               | \-       | top-k 的 k，默认 6         |
| OUTPUT(输出) | topk\_scores   | tensor | (T, k)   | 与 x 一致        | ND       | 选中专家的评分（未归一化） |

### 3.4 关键输入约束

- **数据类型**: float16, float32
- **维度场景**: 2维输入（T, E），T 为 token 数，E 为专家数
- **维度取值范围（均为正整数）**:
	- T（token 数）: \[1, 131072\]
		- E（专家数）: \[64, 1024\]，可为非 2 的幂
		- k: \[1, 64\]，且 k ≤ E

### 3.5 核心属性说明

- **k** （int，默认 6）: 每个 token 激活的专家数量 k，即 top-k 的 k

### 3.6 输出严格要求

- **形状约束**: topk\_scores.shape == (T, k)
- **类型约束**: topk\_scores 数据类型与 router\_logits 一致
- **数值等价**: 输出与 PyTorch 参考实现在合理浮点误差范围内一致
- **中间精度要求**: softplus 与 sqrt 计算必须使用 FP32 精度，避免大 logits 下溢出

### 3.7 特殊值处理规则

- **softplus 数值稳定**: 当 logits 较大时，softplus 计算需避免 exp 溢出（如 x\>20 时 softplus(x)≈x）
- **负无穷 logits**: logits 为负无穷时，softplus 趋近 0，score 趋近 0
- **k=1 边界**: 仅选 1 个专家，输出评分即为该专家对应的 score
- **并列值（tie）处理**: 多个专家的 score 相等时输出值相同，排序顺序不影响结果

## 四、规则要求

1. **评分函数规则**: 评分必须为 `sqrt(softplus(x))`，softplus 定义为 `ln(1 + e^x)`，不得用 sigmoid、softmax 等其他评分函数替代
2. **实现方式规则**: softplus 与 top-k 选择的具体实现方式不限（softplus 可用数值稳定近似、top-k 可用 bitonic sort、堆、分块等），任何与数学定义等价且结果正确的实现均可
3. **中间精度规则**: softplus 与 sqrt 计算必须使用 FP32 精度，最终评分可转回输入精度
4. **排序规则**: 必须按 score 降序取 top-k 个值

## 五、精度判断规则

精度要求：计算结果需满足以下精度误差要求：

- float32：相对误差 \< 1e-4，绝对误差 \< 1e-4（双万分之一精度）
- float16、bfloat16：相对误差 \< 1e-3，绝对误差 \< 1e-3（双千分之一精度）
- int32：要求计算结果完全准确，无误差

## 六、得分规则

- 本次比赛共15个测试点，所有case点精度全部通过才会计分。
- 每个测试点单独计分，逻辑如下（T为最优性能，t为当前提交性能）：
$$
\frac{100}{1+\log_{1.5}\frac{t}{T}}
$$
- 排行榜显示的最终分数为所有case得分的均值。若得分计算一致，则以提交时间进行排序，提交越早，排名越高。
