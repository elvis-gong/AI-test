## 测试2异常修复记录

用户反馈测试1通过，测试2在 host 抛出 `unsupported SqrtSoftplusTopK contract`。当前题面允许 E 为非 2 的幂，而旧代码错误地拒绝这类输入；移除该限制，同时将输入改为按真实字节数的 DataCopyPad，UB 补齐到 32 字节，转换只读补齐范围、top-k 仅处理实际 E 个元素。保留其余 shape/dtype/k 安全检查，并在异常中输出具体参数。

本地从实际 run_kernel 提取 host 校验段进行 C++14 编译验证：E=64..1024、两种 dtype、k=1/6/64 共 5766 组校验及 UB padding 计算通过，错误输出 shape 仍会拒绝并给出参数。该检查不运行 Ascend C kernel，也未模拟 DMA。测试2的具体参数尚未提供，不能断言非 2 的幂就是唯一触发条件；待设备复测确认。

run.sh、main.asc 与 scripts/ 未修改。
